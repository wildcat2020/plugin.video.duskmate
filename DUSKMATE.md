# TMDb Helper — Duskmate build

This branch tracks Jurialmunkey's TMDb Helper and retains the upstream add-on ID and complete feature set.
The Duskmate patch adds only machine-facing setup, status, and structured library-add routes used by the
Duskmate Android application.

Upstream player importing, player configuration, default-player selection, and all related settings remain
unchanged. Duskmate does not bundle, select, inspect, recommend, or configure players or player URLs.
